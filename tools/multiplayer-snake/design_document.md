# 多人貪吃蛇：霓虹戰場 (Snake Neon Battlegrounds) 開發設計書

## 1. 遊戲概覽
這是一款基於 Web 技術的多人即時對戰貪吃蛇遊戲。玩家在同一個無限（或極大）的畫布上競爭，目標是透過吃食與擊敗其他玩家來獲得最大的體型。

## 2. 核心機制與玩法
### 2.1 移動與控制
- **360 度轉向**：玩家使用滑鼠或觸控控制蛇的行進方向（非傳統的 90 度轉向）。
- **能量噴射 (Boost)**：按住滑鼠左鍵可加速 2 倍。加速會消耗蛇身的長度（每秒減少固定長度），並在尾部留下微弱的能量軌跡。

### 2.2 碰撞與死亡
- **死亡判定**：玩家的「頭部」碰到地圖邊緣或其他玩家的「身體」即死亡。
- **殘骸補償**：玩家死亡後，其身體會化為大量高價值的「光點能量」。這會鼓勵玩家進行圍堵與誘敵，增加策略性。

### 2.3 刺激功能 (Excitement Features)
- **多樣化道具 (Power-ups)**：
    - **強力磁鐵 (Magnet)**：擴大吸取能量的半徑。
    - **幽靈化 (Ghost)**：短暫穿透障礙物與其他蛇身。
    - **視角拉遠 (Zoom Out)**：暫時獲得更廣的視野，提早發現敵人。
- **動態地圖區域 (Hot Zones)**：地圖上會隨機出現能量密度極高的「風暴區」，吸引大量玩家聚集亂鬥。

## 3. 技術規格
### 3.1 技術棧
- **渲染引擎**：HTML5 Canvas API。
- **遊戲邏輯**：Vanilla JavaScript / TypeScript。
- **即時同步**：Firebase Realtime Database。
    - 使用 `players/` 路徑儲存座標與狀態。
    - 使用 `points/` 路徑儲存地圖能量位置。
- **狀態管理**：基於時間補間 (Interpolation) 的客戶端預測，減少網路延遲感。

### 3.2 資料結構 (Firebase 預想)

## 4. 視覺與音效
- **風格**：Cyberpunk 霓虹風格。深色背景 (#0d0d0d) 搭配高亮螢光色蛇身。
- **動效**：蛇移動時帶有微妙的拖尾殘影與發光效果。
- **音效**：
    - 吃食時的清脆響聲。
    - 擊殺時的震撼重低音。
    - 排名晉升時的提示音。

## 5. 開發階段
- **第一階段 (MVP)**：建立單機版 Canvas 核心、蛇的移動邏輯。
- **第二階段 (連線)**：整合 Firebase，實現多人座標同步與基礎排行榜。
- **第三階段 (優化)**：加入加速功能、死亡殘骸機制、道具系統。
- **第四階段 (打磨)**：視覺美化、音效整合、跨電腦測試。
